Usage: gitaware missing [flags]

List GitHub repos not cloned under your roots (read-only).

Flags:
  -C string
    	same as -d
  -a	show all repos including clean (○)
  -all
    	same as -a
  -archived
    	include archived in missing
  -check-remote
    	non-mutating: ls-remote to see if remote has updates
  -d string
    	directory to walk (default: config roots, else cwd)
  -depth int
    	max depth when layout=discover (default 3)
  -fetch
    	MUTATING: git fetch before status (asks to confirm)
  -issues
    	show only repos with issues (default)
  -json
    	JSON on stdout (no progress)
  -layout string
    	how to walk: discover (default) | flat | org/repo | host/org/repo
  -missing
    	include uncloned GitHub repos (noisy; prefer: gitaware missing)
  -name string
    	label: remote (default) | path | folder | auto
  -no-color
    	disable colors
  -no-forks
    	exclude forks from missing
  -online
    	use gh (PRs, default branch)
  -org string
    	limit to one org (remote owner)
  -refresh
    	ignore gh cache
  -root string
    	same as -d
  -v	verbose progress on stderr
  -w	include non-git directories
  -workers int
    	parallel workers
  -y	skip confirmation for mutating operations
  -yes
    	same as -y

Commands choose what to do. Flags modify how.

  gitaware              # status, issues only
  gitaware -a           # status, every repo (clean = ○)
  gitaware leave        # don't-walk-away checklist
  gitaware leave -a     # leave rules, but list clean too
  gitaware arrive       # online + fetch
  gitaware prs          # open PRs on current branches
